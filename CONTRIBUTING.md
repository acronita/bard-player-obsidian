# Contributing

Bug reports, ideas and pull requests are welcome.

1. Branch off `develop`: `feature/<name>`, `fix/<name>` or `chore/<name>`.
2. Run `npm install`, then make sure `npm run build` and `npm run lint` pass (and `npm test` once tests exist).
3. Use [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:`, `chore:`).
4. Dependencies are pinned to exact versions; discuss before adding or bumping one.

By contributing, you agree that your contributions are licensed under the project's GPL-3.0 license.
